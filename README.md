# Weather Diary
**Автор:** Чумаков Денис Алексеевич

### Описание
Приложение для ведения личного дневника погоды. Позволяет фиксировать температуру, осадки и описание дня.

### Функции
- **JSON:** Данные сохраняются в `weather_data.json`.
- **Валидация:** Проверка даты и числового формата температуры.
- **Фильтр:** Показ записей теплее заданной температуры.

### Запуск
`python main.py`
